The canonical TMP asset is generated by
`Tools/Fonts/Generate Press Start 2P Static Asset` or Unity batchmode method
`PressStart2PFontGenerator.Generate`. It uses a 2048x2048 single static SDF
atlas, sampling point size 32, padding 5, and fails when any required
player-visible EN/RU/TR glyph is absent.
